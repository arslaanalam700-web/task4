# Reports Directory

This directory stores automated intelligence reports generated by the daily pipeline runner or CLI script.

## Naming Convention
Reports are generated and saved using ISO-formatted dates:
- `YYYY-MM-DD.md`: The complete markdown intelligence briefing with executive summaries, ranked opportunities, competitive analysis, and tactical next steps.
- `YYYY-MM-DD_opportunities.csv`: Accompanying tabular data export of ranked opportunities, components, and evidence links for spreadsheet analysis.

## Attribution & Data Integrity Standards
Every report adheres to strict provenance labeling:
- **Observed Data**: Directly fetched from external APIs or permitted public web scrapers.
- **Derived Analysis**: Mathematically calculated indicators (momentum, relative velocity, opportunity scores).
- **AI-Generated Suggestion**: Strategic synthesis, hook ideation, or content structuring produced by LLM or deterministic fallback rules.
- **Unverified Hypothesis**: Tentative assumptions highlighted when data coverage is partial or unconfirmed.
