# Data Directory

This directory stores database files and offline demonstration fixtures.

## Structure
- `market_intelligence.db`: The local SQLite database generated by runs of the research pipeline (ignored by git).
- `fixtures/`: Curated, verifiable offline datasets used for automated testing, continuous integration, and demo mode when live network access is restricted or throttled.
  - `trends_sample.json`: Real observed relative search interest trends from Google Trends for online education keywords.
  - `competitors_sample.json`: Permitted public crawl observations of online education competitor websites.
  - `audience_sample.json`: Permitted public community questions, intent categorizations, and learner challenges.
